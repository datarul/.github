# Datarul

**Data governance, connected to your data.**

Datarul brings technical metadata, business vocabulary, data lineage and data quality into a shared governance workspace. Explore data assets, understand their meaning and dependencies, and manage the quality of the data your teams use.

[Website](https://datarul.com) · [Installation](https://github.com/datarul/install) · [Contact](mailto:info@datarul.com)

## Platform capabilities

| Capability | Purpose |
| --- | --- |
| Data dictionary | Harvest and organize technical metadata from data sources. |
| Business glossary | Maintain shared business terms, definitions and domains. |
| Data lineage | Explore data dependencies and assess downstream impact. |
| Data quality | Define validation rules, run checks and review results. |
| Report catalog | Catalog business intelligence reports and their metadata. |
| Personal data discovery | Identify potential personal data in English and Turkish text. |

## Getting started

For platform installation, start with the [Datarul installer](https://github.com/datarul/install). It bootstraps the setup toolkit and guides environment configuration and deployment.

The installer obtains the deployment toolkit maintained in `datarul/setup`. Follow the installer documentation for environment settings, upgrades and shared Linux installation permissions.

## About this organization

This GitHub organization hosts the Datarul platform and its supporting installation tools, documentation and engineering projects. Public repositories provide installation entry points; access to platform source repositories is managed separately.

For product information or a deployment discussion, visit [datarul.com](https://datarul.com) or contact [info@datarul.com](mailto:info@datarul.com).
